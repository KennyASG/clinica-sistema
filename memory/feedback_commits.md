---
name: Estilo de commits
description: Convención de commits preferida por el usuario
type: feedback
---

Usar prefijos ADD:, MOD:, FIX: (no feat:/fix:/design: de Conventional Commits).
Mensajes cortos, una línea, sin cuerpo largo.

**Why:** El usuario ya tenía este flujo establecido antes de trabajar con Claude.
**How to apply:** Siempre al hacer commits en este proyecto.

Ejemplos:
- MOD: rediseño bloque Citas
- ADD: modal cancelar cita
- FIX: validación hora en NuevaCitaPage
