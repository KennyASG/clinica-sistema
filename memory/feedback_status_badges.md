---
name: No repetir patrón de badges de estado
description: Evitar bg-{color}-100/text-{color}-700 para todos los estados; usar variedad visual
type: feedback
---

No usar el patrón bg-{color}-100 text-{color}-700 de forma repetitiva para todos los estados de una entidad.

**Why:** El usuario lo notó como una combinación genérica y repetitiva que hace que todas las interfaces se vean iguales.
**How to apply:** Usar variedad: dots de color + texto slate, pills con border, íconos, o colores claramente distintos entre estados. Lo importante es que cada estado se diferencie visualmente de los demás sin que todos sigan el mismo patrón mecánico.
